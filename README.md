# StreamVibe - Netflix-style Streaming UI

Built with React + Vite for SkillMe Week 1 Task.

## Features
- Navbar with logo & profile
- Hero section with Featured show - The Last Signal, video, rating & buttons
- 3 Rows - Trending Now, Comedy, Drama with 12 shows
- Reusable components - ShowCard & ShowRow using props
- Dark theme, hover effect & responsive design

## How to run
npm install
npm run dev
